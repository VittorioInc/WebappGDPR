# GDPR questionnaire — self-hosting

[Italiano](README.it.md)

Standalone GDPR questionnaire with an Italian/English interface, conditional assessment and downloadable PDF.

## Download and run locally

```sh
git clone https://github.com/VittorioInc/WebappTesi.git
cd WebappTesi
npm ci --include=dev
npm run build

npm start
```
